# 🎪 Glyde — In-Event Intelligence Platform

> The app that makes going to events as good as the event itself.

Glyde is a mobile platform that replaces the paper map, the megaphone, and the guesswork — for attendees and venue staff alike.

## Live Demo

👉 **Attendee App:** https://05executor05.github.io/Glyde  
👉 **Manager Dashboard:** https://05executor05.github.io/Glyde/manager.html

## What Glyde Does

| For Attendees | For Venues |
|---|---|
| Interactive venue map | Live report dashboard |
| Friend live location tracking | Real-time crowd analytics |
| In-app food & merch ordering | Vendor order management |
| Event schedule + notifications | Staff assignment system |
| Group chat + venue channels | Emergency announcements |
| XP, badges, Festival Passport | Post-event analytics report |
| Memories & shareable recap | |
